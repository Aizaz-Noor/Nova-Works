## LinkedIn

We built NovaWorks at Infinity Hack ’26. We missed the submission window and did not win, but the project gave us a concrete lesson: integration and delivery need their own time buffer.

The problem was turning a meeting full of suggestions, corrections and final decisions into assigned work.

NovaWorks lets an administrator use the full transcript to create projects and tasks. A real model extracts the plan; the server validates owners, deadlines and estimated hours before saving the batch together. Managers see assigned projects, and developers see their own tasks.

The event version passed thirteen backend tests and genuine original/modified transcript checks. After the event, we continued it as a portfolio project: deployed it on Vercel with Supabase PostgreSQL, improved the interface, and added search over work already authorized for each account. The later version passed thirty-nine backend tests and hosted flow checks. These are bounded verification results, not an accuracy benchmark.

I handled product/UI and integration. Abdullah delivered the backend; Abdul Basit Shahid was part of our Code Nomads team, assigned backend/AI support.

The attached walkthrough shows the current portfolio. It records a new real AI request using fictional data in an isolated local workspace: three projects and twelve tasks.

Try it: https://nova-works-zeta.vercel.app
